## 📋 游戏规则

完整规则请查看 [RULES.md](./RULES.md)

### 基础信息
- **人数**: 4 人
- **牌数**: 2 副牌 (104 张) + 4 张大王 + 4 张小王 = **112 张牌**
- **每人**: 28 张
- **队友**: 对家 2 人为一队

### 特殊规则
- **财神（万能牌/癞子）**: 4 大王 +4 小王 =8 张王，可当任意牌使用（替代任意点数）
- **贡献分**: 打出**5线及以上炸弹**时，根据炸弹线数对应贡献分倍率实时结算
  - 4线炸弹 → **无贡献分**
  - 5线 → 1分，6线 → 2分，7线 → 4分，以此类推（2^(线数-5)）

### 炸弹倍数与贡献分

| 炸弹线数 | 结算倍率 | 贡献分倍率 |
|----------|---------|-----------|
| 4线 | 1 | **无** |
| 5线 | 2 | 1 |
| 6线 | 4 | 2 |
| 7线 | 8 | 4 |
| 8线 | 16 | 8 |
| 9线 | 32 | 16 |
| 10线 | 64 | 32 |
| 11线 | 128 | 64 |
| 12线 | 256 | 128 |
| 13线 | 512 | 256 |
| 14线 | 1024 | 512 |
| 15线 | 2048 | 1024 |
| 16线 | 4096 | 2048 |

## 🎯 发牌器目标

**核心需求**: 保证每个人都有更多的炸弹

### 发牌策略
1. 优先保证每人至少有 1-2 个炸弹
2. 炸弹张数分布均匀（4-8 张混合）
3. 保留王炸和明牌的灵活性
4. 考虑连炸的可能性

## 🚀 使用方式

### 单局发牌
```bash
python dealer.py --players 4 --bombs 2
```

### 批量模拟（生成Excel统计）
```bash
python batch_dealer.py --config config.json
```

### 自定义配置
```bash
python batch_dealer.py --config your_config.json --output ./output
```

## 📊 Excel 统计指标

批量模拟后会生成包含以下指标的 Excel 报告：

| 指标 | 说明 |
|------|------|
| 炸弹总数 | 每人平均每局炸弹数 |
| 4/5/6+张炸弹 | 按炸弹大小分类统计 |
| 万能牌数 | 每人分到的王（财神）数量 |
| 顺子数量 | 5+张连牌（排除炸弹用过的牌） |
| 对子数量 | 2张同点数（排除炸弹用过的牌） |
| 三条数量 | 3张同点数（排除炸弹用过的牌） |
| 贡献分 | 5线及以上炸弹的贡献分总和 |
