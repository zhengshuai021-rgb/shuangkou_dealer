## 📋 游戏规则

### 基础信息
- **人数**: 4 人
- **牌数**: 2 副牌 + 8 张大王 + 2 张小王 = **112 张牌**
- **每人**: 28 张
- **队友**: 对家 2 人为一队

### 牌型（从小到大）

| 牌型 | 示例 | 说明 |
|------|------|------|
| 单张 | A | 任意单张牌 |
| 对子 | AA | 任意 2 张点数相同的牌 |
| 三张 | KKK | 任意 3 张点数相同的牌 |
| 顺子 | 345678 | 5 张及以上点数相邻的单张 |
| 连对 | 334455 | 3 组及以上点数相邻的对子 |
| 三带二 | JJJQQQQKKK | 3 组及以上点数相同的三张 |
| 炸弹 | 2222 | 4 张及以上点数相同的牌 |
| 连炸 | JJJJQQQQKKKK | 3 组及以上点数相邻的炸弹 |
| 连对 | 777788889999 | 3 组及以上点数相邻的连对 |
| 王炸 | 👑👑 或 🃏 | 即大小王，可以替代除明牌外任意一张牌 |

### 特殊规则
- **明牌**: 可以替代除明牌外任意一张牌
- **冲关**: 对局中若出过 5 张及以上炸弹时，根据炸弹张数对应分值翻倍实时结算
- **贡献分**: 每局结束后，组成连炸的炸弹中点数最小的（如 JJJJQQQQKKKK 中的 JJJJ）算作 4 张连炸炸弹

### 炸弹倍数表

| 炸弹张数 | 倍数 | 贡献分倍数 |
|----------|------|------------|
| 4 张 | 1 | 无 |
| 5 张 | 2 | 1 |
| 6 张 | 4 | 2 |
| 7 张 | 8 | 4 |
| 8 张 | 16 | 8 |
| 9 张 | 32 | 16 |
| 10 张 | 64 | 32 |
| 11 张 | 128 | 64 |
| 12 张 | 256 | 128 |
| 13 张 | 512 | 256 |
| 14 张 | 1024 | 512 |
| 15 张 | 2048 | 1024 |
| 16 张 | 4096 | 2048 |

## 🎯 发牌器目标

**核心需求**: 保证每个人都有更多的炸弹

### 发牌策略
1. 优先保证每人至少有 1-2 个炸弹
2. 炸弹张数分布均匀（4-8 张混合）
3. 保留王炸和明牌的灵活性
4. 考虑连炸的可能性
